# my-koza-ai

講座・継続サポートを運営している人向けの Claude Code スキル配布キット（3スキル）。

**解説ページ： https://ryoya9595.github.io/my-koza-ai/**

## これは何

| スキル | 何をするか | 合図 |
|---|---|---|
| my-client-feedback | 毎月届く受講生の素材を整理し、前回との差分を出し、フィードバック文の下書きを作る | `/my-client-feedback` |
| my-ebook-remake | 昔作った電子書籍・無料PDFを、今のお客さん像に合わせて作り直す | `/my-ebook-remake` |
| my-meeting-prep | 面談前に当日メモを作る／面談後に約束・宿題・申し送りを記録する（二刀流） | `/my-meeting-prep` |

## 配布物

- `my-koza-ai-kit.zip` — 渡すZip

Zipの中身：

```
my-koza-ai-kit/
├── はじめにお読みください.md          （受け取った人が最初に読む）
├── 導入手順_ClaudeCodeに読ませる.md    （Claude Codeに読ませる指示書）
├── my-client-feedback/SKILL.md
├── my-ebook-remake/SKILL.md
└── my-meeting-prep/SKILL.md
```

## 導入の流れ

受け取った人が Claude Code に `導入手順_ClaudeCodeに読ませる.md` を読ませると、

1. 3つのスキルがそれぞれ何なのかを説明する
2. 「導入してよろしいですか？（はい／いいえ）」と確認する（一部だけの導入も可）
3. 「はい」をもらってから `~/.claude/skills/` にコピーする
4. **使う順番を案内する**（①→②→③）

という順で進む。**確認前にインストールはされない。既存のスキルやデータも削除しない。**

Mac / Windows どちらにも対応（手順書にPowerShell用コマンドも記載）。

## 設計上の要点

- **3つ同時に始めさせない。** 受け取る側は「教材を消化しきれない」経験を持っていることが多いので、
  「はじめにお読みください」と導入手順の両方で、使う順番（①→②→③）を明示している。
- **初回に業務内容を一問一答でヒアリングする。** どのスキルも、いきなり作り始めずに
  「普段どうやっているか」を1つずつ聞いてから構築する。①は業務ヒアリング（何を見て／どう判断して／何を伝えているか）
  のあとで過去の実例を2〜3個もらい、**話した内容と実際の文章のズレを突き合わせて型を固める**。
  「まとめて説明してください」と丸投げせず、AIが具体例を出して聞く形にしている。
- **③は面談が少なくても導入する前提。** 回数が少ないうちに型を作っておくと増えたときにそのまま回るし、
  記録が溜まること自体が資産になる（2回目以降の準備がラクになる）。
- **全スキル共通で「AIは部下」を明記。** 出力は下書きであって完成品ではない、を各所で繰り返している。
- **薬機法・景表法まわりのガード。** ①②とも初回に「書いてはいけない表現」を決めて設定ファイルに保存し、
  毎回それを読んでから生成する（毎回口頭で言わせない）。
