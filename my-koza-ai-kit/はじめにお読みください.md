# はじめにお読みください（講座運営AIキット・4スキル）

このフォルダは、**Claude Codeに「講座運営のめんどくさい部分」をやってもらうためのスキル4つ**です。

## 入っているもの

| スキル | 何をするか | 合図 |
|---|---|---|
| **①LINE返信の下書き** | お客さんからの質問に、**3パターン**（シンプル／次の1手提案／丁寧）で返信案を出す | `/my-line-reply` |
| **②フィードバック下書き** | 毎月届く受講生の素材（写真・動画・報告）を整理して、前回との差分を出し、フィードバック文の下書きまで作る | `/my-client-feedback` |
| **③電子書籍リメイク** | 昔作った電子書籍・無料PDFを、今のお客さん像に合わせて作り直す | `/my-ebook-remake` |
| **④面談準備** | 面談の前に相手の記録を集めて当日メモを作る／面談後に約束・宿題を記録する | `/my-meeting-prep` |

---

## ⚠️ 大事なお願い：4つ同時に始めないでください

4つとも入りますが、**使うのは1つずつ**にしてください。

一度に全部やろうとすると、だいたい全部中途半端になります。
（「講座をたくさん買ったのに消化しきれなかった」経験、心当たりがあると思います。あれと同じことが起きます）

### おすすめの順番

**1️⃣ まず ①LINE返信の下書き から**

理由：**毎日いちばん発生する作業**だからです。
効果を実感する回数が一番多いので、「AIに任せると本当にラクになる」という感覚をここで掴めます。ここが掴めると残りが一気に早くなります。

> 💡 LINE公式アカウントの**チャットProオプション**（月額3,000円・税別）に入っていると、過去のチャット履歴をCSVで書き出して読み込ませられます。
> **入っていなくても使えます。**その場合は画面から代表的なやりとりを20〜30件だけ手で拾えば十分です。

**2️⃣ 次に ②フィードバック下書き**

理由：**毎月必ず発生する作業**なので、こちらも効果がすぐ分かります。①で操作に慣れてから入ると、設定もスムーズです。

**3️⃣ 次に ③電子書籍リメイク**

理由：ここは**売上の入り口**です。①②で操作に慣れてから取りかかると、途中で止まりません。

**4️⃣ 最後に ④面談準備**

理由：①②と違って**毎日使うものではない**ので、後回しで構いません。
ただし**面談の回数が少なくても、入れておく価値はあります。**
回数が少ないうちに型を作っておくと、面談が増えたときにそのまま回りますし、記録が溜まること自体が資産になります（2回目以降の準備が毎回ラクになります）。

## 使う前に必要なもの

- **Claude Code**（デスクトップアプリ）※ Mac / Windows どちらでもOK
- それだけです。**Chrome拡張などは不要**です

> 💡 ①LINE返信で過去履歴をCSVで書き出したい場合のみ、LINE公式アカウントの**チャットProオプション**（月額3,000円・税別）が必要です。無くても使えます。

## 導入のしかた（3ステップ）

### 1. このフォルダをどこかに置く

Zipを解凍して出てきた `my-koza-ai-kit` フォルダを、デスクトップなど分かる場所に置いてください。

### 2. Claude Codeを開いて、こう頼む

チャットに、このまま貼り付けてください：

```
my-koza-ai-kit というフォルダの中の「導入手順_ClaudeCodeに読ませる.md」を探して読んで、その手順どおりに進めてください。フォルダはデスクトップかダウンロードフォルダにあります。
```

> 💡 **もっと確実なやり方**：`my-koza-ai-kit` フォルダを Claude Code のチャット欄に**ドラッグ＆ドロップ**してから、
> 「このフォルダの `導入手順_ClaudeCodeに読ませる.md` を読んで、その手順どおりに進めてください」
> と送ると、場所を探す手間がなくなります。

すると Claude Code が

- **4つのスキルがそれぞれ何なのかを説明** →
- **「導入してよろしいですか？」と確認** →
- あなたが「はい」と答えてから導入

という流れで進めます。**勝手にインストールされることはありません。** 内容を聞いて「やっぱりやめる」と言えば、そこで止まります。

> 🔒 **今あるデータや、すでに入っている他のスキルが消えることはありません。**
> この導入でやるのは「`~/.claude/skills/` の中に新しいフォルダを4つ作って、ファイルを置く」だけです。削除も上書きもしません。

### 3. Claude Codeを再起動する

再起動したら、チャットで `/my-line-reply` と打てば①が使えます。

## 初回だけ、いろいろ質問されます

どのスキルも、**初めて動かすときに「あなたのやり方」を聞いてきます。**

これは面倒に感じるかもしれませんが、**ここが一番大事なところ**です。
ここを丁寧に答えるほど、2回目以降の精度が変わります。

たとえば①LINE返信だと：

- よく来る質問を5つほど挙げてください
- その返信で、何をしたいですか？（安心させたい／行動してほしい／情報を渡すだけ）
- **1件あたり何分くらいかけていますか？溜まってしまうのはどんな質問のときですか？**
- 返信で気をつけていること／絶対に省かないことは何ですか？
- 過去のチャット履歴を読み込ませてください（CSV、または代表20〜30件）
- 書いてはいけない表現はありますか？

そのあと、過去の返信から**「これがシンプル形式、これが丁寧形式で合ってますか？」**と実例を見せて確認してきます。
**自分で定義を考える必要はありません。**

> 💡 **一問一答で進みます。** AIが1つずつ質問してくるので、それに答えていくだけです。
> 「まとめて説明してください」とは聞かれないので、**うまく言葉にできなくても大丈夫**です。
> 答えにくい質問には「たとえば◯◯な場合は？」と具体例で聞き直してくれます。

## いちばん大事な考え方：AIは部下です

このキットのスキルが作るのは、**すべて「下書き」**です。完成品ではありません。

- **判断するのはあなた。AIは整理係です**
- 出てきたものを**そのまま使わないでください。必ず目を通してから**
- 「ここ違う」と言えば直します。その修正を繰り返すほど、あなたの型に近づきます

AIを上司だと思ってしまうと、AIが言ったことが正解に見えてしまいます。
**部下が作った資料をチェックする**、くらいの感覚がちょうどいいです。

## このキットがやらないこと

- **あなたの確認なしに、誰かにメッセージを送ることはありません**（下書きまでです）
- 既存のファイル・スキル・設定を削除したり上書きしたりしません
- 効果や成果を断定する文章は書きません（分野によって危ない表現があるので、初回にルールを決めます）

## 困ったら

| 症状 | 対処 |
|---|---|
| `/my-line-reply` などが出てこない | Claude Codeを再起動する |
| 下書きが自分の言葉じゃない | 「ここ違う」と伝えて直してもらう。過去に自分が書いた文章を追加で貼るともっと合ってくる |
| 初回の質問が多くて面倒 | 一度で全部答えなくてOK。「後で決める」と言えば飛ばせます |
| Windowsでコマンドがエラーになる | Claude Codeに「Windowsなので、PowerShell用のコマンドで進めて」と伝えてください（手順書にWindows用も書いてあります） |
| 4つとも使いこなせる気がしない | **①だけで大丈夫です。** 1つがちゃんと回るようになってから次に行ってください |

それでもダメなら、りょうやさんに聞いてください。
