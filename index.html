Claude Code スキル ・ my-koza-ai

講座運営を、
AIに手伝わせる。

講座や継続サポートを運営していると増えていく「めんどくさいところ」を、Claude Codeに任せるスキル4点セット。初回にあなたのやり方を聞き取って、あなた専用の形で組み上げます。

1導入する
2やり方を答える
3下書きが出る
01 LINE REPLY
返信案を3つ用意しました
シンプル／次の1手提案／丁寧
02 FEEDBACK
今月の変化を整理しました
前回との差分／下書き／次月に見るポイント
03 EBOOK
旧版から構成を立て直します
構成案を3つ ⇢ 章ごとに執筆
04 MEETING
前回の約束が2件あります
現在地／宿題／今日話すこと
▍ 聞く → 整理する → 下書き

入っているのは、4つ。

どれも「あなたの代わりに考える」のではなく、「あなたが判断する材料を整える」ためのものです。出てくるのは全部下書きです。

1まずこれから

LINE返信の下書き

お客さんから届いた質問に、3パターンで返信案を出します。①シンプル形式（答えだけ）②次の1手提案形式（答え＋次にやること1つ）③丁寧形式（受け止めてから答える）。そのうえで「今回はこれが合いそうです」と1つ推します。

/my-line-reply
2次にこれ

フィードバック下書き

毎月届く受講生の素材（写真・動画・報告フォーム）を読んで、前回との差分を出し、フィードバック文の下書きまで作ります。毎月必ず発生する作業なので、効果がすぐ分かります。

/my-client-feedback
3次にこれ

電子書籍リメイク

昔作った電子書籍や無料PDFを、今のお客さん像に合わせて作り直します。ゼロから書き直すのではなく、旧版を読み込んで土台にするので手が止まりません。

/my-ebook-remake
4最後にこれ

面談準備

面談前にその人の記録を集めて当日メモを1枚作ります。面談後は文字起こしを渡すと、決まったこと・宿題・申し送りを記録します。前と後の二刀流。

/my-meeting-prep
⚠️ 4つ同時に始めないでください。 一度に全部やろうとすると、だいたい全部中途半端になります。①→②→③→④の順で、1つがちゃんと回るようになってから次に進んでください。導入は4つまとめてで構いません。

まず聞く。それから作る。

どのスキルも、いきなり作り始めません。初回に「普段どうやっているか」を一問一答で聞き取って、あなた専用の設定として保存します。

1
何をやっているかを聞く

素材のどこを、どの順番で見ているか。「順調」と思う基準は何か。何を伝えていて、逆に何は書かないようにしているか。まとめて説明する必要はありません。1問ずつ聞かれるので、答えていくだけです。

2
実物を読み込む

過去のチャット履歴（LINE返信）、過去に書いたフィードバック、旧版の電子書籍。実物から、書き出し・長さ・語尾の癖・よく使う言い回しを読み取ります。①では「これがシンプル形式、これが丁寧形式で合ってますか？」と、あなたの過去の返信から実例を拾って見せます。定義を自分で考える必要はありません。

3
ズレを突き合わせる

話して聞いた内容と、実際の文章が違うことがあります。そのときは黙って片方を採るのではなく、「お話では◯◯でしたが、実際は△△でした。どちらに寄せますか？」と確認します。このズレを潰す作業が、型を固める一番の近道です。

4
書いてはいけない表現を決める

分野によっては危ない表現があります（「治る」「改善する」などの断定）。初回にルールを決めて設定ファイルに保存し、毎回それを読んでから下書きを作ります。毎回口で言う必要はありません。

設定は保存されて、育ちます。 出てきた下書きに「ここ違う」と伝えるたび、その修正が型に反映されます。3〜4回も繰り返せば、かなりあなたの言い方に寄ってきます。

AIは部下です。上司ではありません。

このキットが作るのは、すべて「下書き」です。完成品ではありません。

●判断するのはあなた。AIは整理係です
●出てきたものは必ず目を通してから使う
●写真や動画の読み取りには限界があるので、断定形では書きません
●「ここ違う」と言えば直します。それが型になります
✕あなたの確認なしに、誰かへ送信することはありません
✕既存のファイル・スキル・設定を削除も上書きもしません
✕効果や成果を断定する文章は書きません
✕素材が足りないとき、推測で埋めません（確認してきます）
AIを上司だと思ってしまうと、AIが言ったことが正解に見えてしまいます。部下が作った資料をチェックする、くらいの感覚がちょうどいいです。

導入は確認つき。勝手には入らない。

受け取った人が Claude Code に手順書を読ませると、この順で進みます。

1
4つのスキルが何なのかを説明する

何ができて、何をしないか。どこにファイルが入るか。

2
「導入してよろしいですか？」と聞く

「はい」をもらうまで、ファイルのコピーも設定変更も一切しません。4つのうち一部だけ入れることもできます。

3
フォルダを作ってコピーする

mkdir と cp だけ。削除・移動系のコマンドは使いません。同名スキルがあれば必ず確認します。

4
使う順番を案内する

①→②→③→④。ここを飛ばさないよう手順書に明記してあります。

Mac / Windows どちらにも対応。手順書にはPowerShell用のコマンドも併記してあるので、Windowsの人は「Windowsなので、PowerShell用のコマンドで進めて」と伝えれば大丈夫です。

よくある質問

面談があまり多くないのですが、③は入れる意味ありますか？あります。回数が少ないうちに型を作っておくと、面談が増えたときにそのまま回ります。それに記録が溜まること自体が資産になります（2回目以降の準備が毎回ラクになります）。月に1回しかやっていなくても、そのまま入れて大丈夫です。
①でチャットProオプションに入っていないとダメですか？いいえ、無くても使えます。加入していればチャット履歴をCSVで書き出して丸ごと読み込ませられますが、未加入でも画面から代表的なやりとりを20〜30件手で拾えば十分に機能します。むしろ「これはいい返信ができた」と思うものを厳選した方が、精度が上がることもあります。
返信を勝手に送られたりしませんか？送りません。このスキルが作るのは下書きだけです。あなたがコピーしてLINEに貼る、が唯一の送り方です。チャット履歴に含まれる個人情報も、外部に送ったり共有したりしません。
自分のやり方をうまく説明できる自信がありません大丈夫です。「まとめて説明してください」とは聞かれません。1問ずつ具体的に聞かれるので、答えていくだけです。答えにくいときは「たとえば◯◯な場合はどうしてますか？」と例を出して聞き直してくれます。
出てきた下書きが自分の言葉じゃない気がします「ここ違う」と伝えて直してもらってください。その修正が設定に反映されます。過去に自分が書いた文章を追加で貼ると、もっと寄ってきます。
4つとも使いこなせる気がしません①だけで大丈夫です。1つがちゃんと回るようになってから次に行ってください。4つ入れておいて、使うのは1つ、で全く問題ありません。
今あるスキルやデータが消えたりしませんか？消えません。この導入でやるのは「.claude/skills/ の下に新しいフォルダを4つ作って、ファイルを置く」だけです。削除も上書きもしません。手順書でも rm や mv を使わないよう明記してあります。
